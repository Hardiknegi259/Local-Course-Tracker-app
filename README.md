# Ledger — Offline Course Progress Tracker

A minimal, fully offline Android app for tracking lecture progress across self-defined courses. No login, no internet connection, no cloud sync — just add a course, log lectures as you complete them, and everything stays stored on your device.

Built as a light-weight web app (HTML/CSS/JS) wrapped into a native Android app using [Capacitor](https://capacitorjs.com/), with [SQLite](https://github.com/capacitor-community/sqlite) for local, offline-first data persistence.

## Features

- **Add courses** — name them yourself, set the total number of lectures
- **Track progress** — increment or decrement completed lectures with a simple +/− stepper
- **Mark complete** — flag a course as finished at any point
- **Delete courses** — remove a course (with a confirmation step to avoid accidental taps)
- **Fully offline** — no network calls, no backend, no account required
- **Low memory footprint** — no frameworks, just vanilla HTML/CSS/JS wrapped natively

## Tech Stack

| Layer          | Technology                                                                                                |
| -------------- | --------------------------------------------------------------------------------------------------------- |
| UI             | HTML, CSS, vanilla JavaScript                                                                             |
| Native wrapper | [Capacitor](https://capacitorjs.com/)                                                                     |
| Local storage  | SQLite via `@capacitor-community/sqlite` (falls back to `localStorage` when opened directly in a browser) |
| Platform       | Android                                                                                                   |

## Data Model

```sql
CREATE TABLE courses (
  id INTEGER PRIMARY KEY AUTOINCREMENT,
  name TEXT NOT NULL,
  total_lectures INTEGER NOT NULL,
  completed_lectures INTEGER DEFAULT 0,
  is_completed INTEGER DEFAULT 0
);
```

## Getting Started

### Prerequisites

- [Node.js](https://nodejs.org/) (includes npm)
- [Android Studio](https://developer.android.com/studio) (includes the Android SDK and Gradle)

### Setup

```bash
git clone https://github.com/<your-username>/course-tracker.git
cd course-tracker
npm install
```

### Run in a browser (quick preview, uses localStorage)

Just open `www/index.html` directly in a browser. Useful for testing UI and logic before building the native app.

### Build the Android app

```bash
npx cap sync android
npx cap open android
```

This opens the project in Android Studio. From there:

```
Build → Generate App Bundles or APKs → Generate APKs
```

The installable APK will be generated at:

```
android/app/build/outputs/apk/debug/app-debug.apk
```

Transfer this file to an Android device and install it (you'll need to allow "install from unknown sources" the first time).

## How It Works

The app detects at runtime whether it's running inside a Capacitor-wrapped native shell or a plain browser:

- **Inside the native app** → uses real SQLite for persistent, offline storage
- **In a plain browser** → falls back to `localStorage`, so the UI is fully testable without building the Android app first

This means the same `www/` code works both as a quick browser prototype and the final installed app, with no code changes needed between the two.
